# Conference Management App

## Description
Salesforce Conference Management App built as part of assessment.  
Includes:
- LWC components
- Apex classes
- Trigger for conflict management
- Lightning Message Channel
- Lightning App Page

## Setup
1. Deploy to Salesforce Using Lightning Studio
2. Assign custom objects
3. Add Lightning App Page to Conference App

## Components
- speakerSearch
- speakerList
- bookSession
- SpeakerController
- SpeakerAssignmentHandler
- SpeakerAssignmentTrigger
- SpeakerSelected.messageChannel
